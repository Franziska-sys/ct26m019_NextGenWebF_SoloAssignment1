# Counter

A small counter component built with Vue 3 and TypeScript.

## Features

* The counter starts at 0
* Buttons to count up and down
* A derived value that shows the count doubled

## Getting started

Node.js needs to be installed. Then run the following commands in the project folder.

```bash
npm install
npm run dev
```

## Structure

* `Counter.vue` holds the state and the buttons
* `App.vue` renders the Counter component
